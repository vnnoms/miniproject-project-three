About TutorIn

A student-driven peer-to-peer engineering network founded to bridge technical comprehension gaps among early-stage computer science students. The hub provides structured, low-intimidation peer mentorship through weekly code reviews, algorithmic logic workshops, and interface engineering clinics, fostering an accessible and collaborative environment for practical software development.

Services

We offer a range of services to support the learning journey and facilitate peer knowledge sharing among students of the Department of Computer Engineering and Informatics at Politeknik Negeri Bandung.

  • Weekly Peer Code Reviews
  • Algorithmic Logic Workshops
  • Semantic Web & Interface Engineering Clinics
